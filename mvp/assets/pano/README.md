# 파노라마 넣는 곳

D5에서 렌더한 360° equirectangular 이미지를 이 폴더에 넣는다. **JPG(압축본)와 누끼(`_cut.png`)만 GitHub에 올라가고**, 원본 PNG와 `built/`(pano:prep 결과)는 올라가지 않는다. 주고받는 방법은 [`../../README.md`](../../README.md) 2-1.

## 파일 이름 규칙

```
{시점}_island{아일랜드}_floor{바닥재}_{크기}.jpg
```

| 자리 | 값 | 뜻 |
|---|---|---|
| 시점 | `v1` `v2` | V1 정면 / V2 측면 (시점을 늘리면 `scene.js`에 추가) |
| 아일랜드 | `0` `1` `2` `3` | 0 = 없음 |
| 바닥재 | `0` `a` `b` `c` | 0 = 기존 바닥 |
| 크기 | `8k` `4k` | 8k = 8192×4096(아이맥), 4k = 4096×2048(아이패드) |

예: `v1_island0_floor0_8k.jpg`(아일랜드 없는 지금 주방), `v2_island2_floorb_8k.jpg`(V2 · 아일랜드 2 · 바닥재 B)

- 대소문자·확장자(jpg/png/webp)는 상관없다. 전시용은 JPG(품질 90 안팎)를 권장한다. 같은 화질이면 PNG보다 훨씬 가볍다.
- **8K만 렌더하면 된다.** `npm run pano:prep`이 아이패드용 4K JPG와 누끼 레이어를 `built/`에 만든다.
- **누끼**: 옵션 렌더와 같은 이름 + `_cut.png`(예: `island_a_cut.png`). 원본과 같은 크기, 배경 투명. 이게 있으면 화면은 배경을 고정한 채 이 누끼만 겹친다.
- 크기 표시(`_8k`)를 안 붙인 파일은 8K로 본다.
- 웹 업로드는 한 장 25MB까지다. 8K JPG를 품질 80~90%로 저장하면 대부분 넘지 않는다 ⚠️검증 필요
- 인식된 파일 목록: `http://localhost:3000/api/panos`. 없는 조합은 화면에 테스트 격자(장면 이름 표시)로 보인다.
- D5 이름 그대로 쓰는 별칭(`src/shared/scene.js`의 `ALIASES`): `pano_front` = 정면·옵션 전, `pano_side` = 측면·옵션 전, `island_a` = 측면·아일랜드 2·기존 바닥(누끼: `island_a_cut.png`)

## 렌더 목록

체험 규칙상 "아일랜드 없음"은 기존 바닥과만 쓰므로, 시점 하나당 **13장**이다.

| 아일랜드 \ 바닥 | 기존(0) | A | B | C |
|---|---|---|---|---|
| 없음(0) | ● | – | – | – |
| 1 | ● | ● | ● | ● |
| 2 | ● | ● | ● | ● |
| 3 | ● | ● | ● | ● |

| 시점 | 장수 | 우선순위 |
|---|---|---|
| V1 정면 | 13 | 필수 |
| V2 측면 | 13 | 시간이 모자라면 시나리오 조합(없음, 아일랜드 2 × 기존·B)만 3장 |

8K 렌더에서 GPU가 버티지 못하면 6K(6144×3072)로 렌더해도 코드는 그대로 동작한다. 아이맥에서 약간 덜 선명할 수 있다. ⚠️검증 필요(D5 렌더 시간은 PC 사양에 따라 다름)

## 카메라·노출 체크 (중요)

- **같은 시점의 렌더는 카메라를 절대 움직이지 않는다.** 누끼는 기본 배경 위 같은 자리에 겹쳐지므로, 카메라가 조금만 움직여도 어긋난다.
- **D5 노출·화이트밸런스를 수동으로 고정한다.** 자동 노출이면 오브제 렌더의 톤이 배경과 달라져 누끼가 떠 보인다. ⚠️검증 필요(D5 메뉴 위치는 버전마다 다름)
- 시점마다 **기본 배경(아일랜드 없음·기존 바닥)이 꼭 있어야** 레이어 방식이 동작한다.

- **모든 시점의 카메라 회전값(방향)을 똑같이 둔다.** 각 시점에서 아일랜드 쪽으로 카메라를 돌리지 말고 위치만 옮긴다. 그래야 "yaw 0° = 같은 벽"이 모든 시점에서 유지되고, 시점을 옮겨도 보던 방향이 이어진다.
- 높이 1.6m(소비자 눈높이).
- 각 시점 카메라의 SketchUp 좌표(x, y, z)를 메모해 둔다. 나중에 "다른 자리에서 같은 대상 보기"(안 2)와 매니저 위치 표시에 쓴다.
- 가로:세로 = 2:1.
