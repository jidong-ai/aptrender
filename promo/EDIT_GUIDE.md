### 모션 규칙

- 인트로: 어절마다 0.35초 동안 투명→불투명, 아래 16px에서 제자리로. 0.12초 간격.
- 장면: UI 컴포넌트마다 0.4초 동안 투명→불투명, 아래 16px에서 제자리로. 0.2초부터 0.18초 간격. 다 뜬 뒤에는 정지한다. 줌은 쓰지 않는다.
- 등장 순서와 좌표는 `promo/motion/scenes.json`, 인트로는 `promo/intro/layout.json`에 있다.
- 편집 프로그램에서 직접 만든다면: 레이어를 컴포넌트마다 나누고, 각각 불투명도 0→100%와 위치 Y +16→0(0.4초, ease-out)을 0.18초씩 밀어 배치한다.

- 2-3·2-4는 왼쪽에 확대 UI, 오른쪽에 XR 화면을 둔 2단 구성이다.

### 녹화 클립 넣는 법

클립 재생 속도는 원본의 약 1.9배다(`edit.json`의 `clipSpeed`). 장면 영상 위 트랙에 얹고, 위치와 크기는 Figma의 `SCREEN_SLOT_*` 레이어(숨김 상태)와 같게 맞춘다.

| 장면 | 슬롯 | x, y, 너비×높이 | 모서리 | 시작 | 사용 구간(클립 파일 기준, 초) |
|---|---|---|---|---|---|
| 2-1 | XR | 831, 372, 870×608 | 16 | 1.5초 | 0.8–5.0 → 27.5–31.8 → 36.0–45.7 |
| 2-1 | 태블릿 화면 | 277, 388, 477×334 | 10 | 1.5초 | XR과 같은 구간 |
| 2-2 | XR | 831, 372, 870×608 | 16 | 1.68초 | 1.5–21.6(이어서 한 덩어리) |
| 2-2 | 태블릿 화면 | 277, 388, 477×334 | 10 | 1.68초 | XR과 같은 구간 |
| 2-3 | XR | 831, 435, 870×489 | 16 | 1.32초 | 2.0–20.7(이어서 한 덩어리) |

- 크기: 슬롯을 꽉 채우도록 키우고 넘치는 부분은 자른다. XR 클립은 16:9라 2-1·2-2에서 좌우가 조금 잘린다.
- 모서리: 프리미어는 '크롭 + 둥근 사각형 마스크', 캡컷은 '마스크 › 사각형 › 둥근 정도'로 맞춘다.
- 사용 구간 값은 지금 녹화본 기준이다. 다시 녹화하면 `out/timeline.json`의 단계 시각이 바뀌므로, 프리뷰를 다시 만들어 확인한다.
- 녹화 장면 순서
  - 2-1: 무드보드 공유 → 치수 확인 → 900mm 지점에 체크 그리기
  - 2-2: 아일랜드 3개 제안 → 김민선이 b를 고름 → "이 제품이 가격, 디자인 모두 제일 마음에 들어요"
  - 2-3: 바닥재 칩 선택 → 적용하기 → 김민선이 포틀랜드를 고름 → "이 제품이 잘 어울리는 것 같아요"

## 텍스트와 금액

- 모든 텍스트는 Pretendard다. 이 작업에서는 글자를 새로 쓰지 않고 이동·크기 조절·복제·숨김·색 변경만 했으므로 글꼴을 다시 바꿀 필요가 없다.
- **2-3 예상 금액은 프로토타입 계산값 1,749,000원으로 바꿨다.** 세로 영상 원본은 1,021,400원이다.
  - 계산식: `mvp/src/shared/catalog.js`의 `estimate()`, 아일랜드 b + 포틀랜드 기준
  - 아일랜드 690,000 + 설치 120,000 + 바닥재 62,000원/㎡ × 9.5㎡(589,000) + 기존 바닥 철거 350,000
  - 2-3 왼쪽 확대 패널과 오른쪽 XR 화면 모두 같은 금액이다. 녹화 클립의 XR 화면도 같은 금액이다.
  - 함께 바꾼 표시: 타일 "9.5㎡, 포틀랜드 모티프", 아일랜드 "아떼 원목 식탁, 마호가니"

## 다시 만들기

프로토타입 녹화(전시 PC 권장. 창을 띄우면 GPU를 써서 파노라마가 부드럽다):

```bash
cd mvp && npm i -D playwright && npx playwright install chromium
```

```bash
npm run promo:record -- --headed
```

인트로·장면 모션 영상(프리뷰보다 먼저):

```bash
python3 promo/build-intro.py
```

```bash
python3 promo/build-motion.py
```

프리뷰 조립(ffmpeg 필요):

```bash
python3 promo/build-preview.py
```

한 장면만:

```bash
python3 promo/build-motion.py --only 2-3 && python3 promo/build-preview.py --only 2-3
```

Figma에서 장면을 고쳤다면 배경(컴포넌트를 숨긴 상태)과 바뀐 컴포넌트를 PNG(1x)로 다시 내보내 `promo/motion/<장면>/`의 같은 이름 파일을 덮어쓰고, 위치가 바뀌었으면 `scenes.json`의 좌표도 고친다.
