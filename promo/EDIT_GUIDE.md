### 인트로 모션

- 어절별 등장: 어절마다 0.35초 동안 투명→불투명, 아래 16px에서 제자리로. 0.12초 간격으로 차례로 뜬다. 카드(사진+라벨)는 한 덩어리로 같은 방식이다.
- 어절은 Figma에서 내보낸 텍스트 PNG를 그대로 잘라 쓴다. 굵기·색이 섞인 문장도 Figma 렌더 그대로 나온다.
- 등장 시각과 길이는 `promo/intro/layout.json`의 `at`·`dur`로 고친다.
- Figma 인트로 문구를 고쳤다면, 해당 요소를 PNG(1x)로 다시 내보내 `promo/intro/`의 같은 이름 파일을 덮어쓰고 `layout.json`의 `text`도 맞춘다. 어절 수를 이 문장에서 센다.
- 편집 프로그램에서 직접 만든다면: 텍스트 레이어를 어절마다 나누고, 각각 불투명도 0→100%와 위치 Y +16→0(0.35초, ease-out)을 0.12초씩 밀어 배치한다.

## 프레임 레이아웃 규칙 (H3·1-0·1-1 수정본 기준)

- 소제목
  - 내용 프레임: (110, 130). 아이브로우 35.8px, 바로 아래 헤드라인 45.5px
  - H3·E1처럼 가운데 정렬형: y=130. 아이브로우 39.3px, 헤드라인 50.1px, 카드 y=422
- 캡션은 소제목 아래 73px, x=110에 30px로 둔다. 시각 요소(목업·대시보드)는 y=320부터 시작한다.
- step(3D 스캔·XR 상담·시공 진행)은 챕터 간지 1-0·2-0·3-0에만 둔다. 785×73, (558, 130).
- 챕터 간지는 흰 글래스 박스 대신 `whitedim`(흰색 50%)으로 배경과 구분한다. 큰 도면 이미지(높이 450, y=286) 아래에 [번호 + 알약] 줄(y=755)과 설명(30px, y=862)을 둔다.
- 2-0 설명은 H3에서 고친 "오늘의집 북촌 쇼룸 B1F"를 복제해 썼다(기존 '안국' 문구는 숨김).
- **2-0·3-0 설명은 장소 이름뿐이다.** 1-0("인테리어 희망 장소를 모바일로 촬영하는 준비 단계")처럼 문장으로 맞추려면 Figma에서 직접 입력해야 한다. 작업 환경에 Pretendard가 없어 새 글자를 넣지 않았다. 제안 문구:
  - 2-0: "XR 쇼룸에서 매니저와 같은 공간을 보며 상담하는 단계"
  - 3-0: "상담 결과대로 공정을 나눠 시공을 진행하는 단계"
- 캡션 일부는 원본이 가운데 정렬이라 가운데 정렬 그대로 왼쪽 열에 놓였다(2-2~3-3). 왼쪽 정렬로 바꾸려면 Figma에서 정렬만 바꾸면 된다.

- 2-1의 녹화 장면 순서: 무드보드 공유(S2-1) → 치수 확인(S2-2a) → 900mm 지점에 체크 그리기(S2-2c).
- 2-2: 아일랜드 3개 제안 → 김민선이 b를 고름 → "이 제품이 가격, 디자인 모두 제일 마음에 들어요".
- 2-3: 바닥재 칩 선택 → 적용하기 → 김민선이 포틀랜드를 고름 → "이 제품이 잘 어울리는 것 같아요".

## 텍스트와 금액

- 모든 텍스트는 Pretendard다. 2차 수정에서는 글자를 새로 쓰지 않고 이동·크기 조절·복제·숨김만 했으므로 글꼴을 다시 바꿀 필요가 없다.
- **2-3 예상 금액은 프로토타입 계산값 1,749,000원으로 바꿨다.** 세로 영상 원본은 1,021,400원이다.
  - 계산식: `mvp/src/shared/catalog.js`의 `estimate()`, 아일랜드 b + 포틀랜드 기준
  - 아일랜드 690,000 + 설치 120,000 + 바닥재 62,000원/㎡ × 9.5㎡(589,000) + 기존 바닥 철거 350,000
  - 원본 텍스트는 숨김 처리했고, 그 위에 같은 크기로 새 텍스트를 얹었다. 녹화 클립의 XR 화면도 같은 금액이다.
  - 함께 바꾼 표시: 타일 "9.5㎡, 포틀랜드 모티프", 아일랜드 "아떼 원목 식탁, 마호가니"

## 다시 만들기

프로토타입 녹화(전시 PC 권장. 창을 띄우면 GPU를 써서 파노라마가 부드럽다):

```bash
cd mvp && npm i -D playwright && npx playwright install chromium
```

```bash
npm run promo:record -- --headed
```

프리뷰 다시 조립(ffmpeg 필요):

```bash
python3 promo/build-preview.py
```

한 장면만:

```bash
python3 promo/build-preview.py --only 2-3
```

인트로 모션 다시 만들기(프리뷰보다 먼저):

```bash
python3 promo/build-intro.py
```

헤드라인 타이핑 버전:

```bash
python3 promo/build-intro.py --typing --only intro02
```

Figma 프레임을 고쳤다면 해당 프레임을 PNG(1x)로 내보내 `promo/frames/`의 같은 이름 파일을 덮어쓴다.
