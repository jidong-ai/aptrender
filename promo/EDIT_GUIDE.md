### 녹화 클립 넣는 법

클립은 프레임 위 트랙에 얹는다. 위치와 크기는 Figma의 `SCREEN_SLOT_*` 레이어와 같다(숨김 상태라 눈에는 안 보인다. 레이어 패널에서 켜면 위치가 보인다).

| 장면 | 슬롯 | x, y, 너비×높이 | 모서리 | 사용 구간(클립 파일 기준, 초) |
|---|---|---|---|---|
| 2-1 | XR | 1050, 229, 768×537 | 18 | 0.8–5.0 → 27.5–31.8 → 36.0–45.7 |
| 2-1 | 태블릿 화면 | 790, 668, 475×332 | 10 | XR과 같은 구간 |
| 2-2 | XR | 1050, 229, 768×537 | 18 | 1.5–21.6(이어서 한 덩어리) |
| 2-2 | 태블릿 화면 | 790, 668, 475×332 | 10 | XR과 같은 구간 |
| 2-3 | XR | 743, 398, 1087×612 | 24 | 2.0–20.7(이어서 한 덩어리) |

- 크기: 슬롯을 꽉 채우도록 키우고 넘치는 부분은 자른다. XR 클립은 16:9라 2-1·2-2에서 좌우가 조금 잘린다.
- 모서리: 프리미어는 '크롭 + 둥근 사각형 마스크', 캡컷은 '마스크 › 사각형 › 둥근 정도'로 맞춘다.
- 사용 구간 값은 지금 녹화본 기준이다. 다시 녹화하면 `out/timeline.json`의 단계 시각이 바뀌므로, 프리뷰를 다시 만들어 구간을 확인한다.
- 2-1의 녹화 장면 순서: 무드보드 공유(S2-1) → 치수 확인(S2-2a) → 900mm 지점에 체크 그리기(S2-2c).
- 2-2: 아일랜드 3개 제안 → 김민선이 b를 고름 → "이 제품이 가격, 디자인 모두 제일 마음에 들어요".
- 2-3: 바닥재 칩 선택 → 적용하기 → 김민선이 포틀랜드를 고름 → "이 제품이 잘 어울리는 것 같아요".

## 텍스트와 금액

- 대부분의 글자는 세로 영상의 Pretendard 레이어를 그대로 복제했다.
- 아래 레이어는 작업 환경에 Pretendard가 없어 **Noto Sans KR**로 넣었다. 레이어 이름 끝에 `(신규·Pretendard로 교체 권장)`이 붙어 있다. Figma에서 선택 후 글꼴만 Pretendard로 바꾸면 된다.
  - H1 리드·헤드라인
  - 2-1 아이브로우·헤드라인·캡션
  - E1 아이브로우·헤드라인·통계 카드·출처
  - 2-3 금액·적용 제품 문구
- **2-3 예상 금액은 프로토타입 계산값 1,749,000원으로 바꿨다.** 세로 영상 원본은 1,021,400원이다.
  - 계산식: `mvp/src/shared/catalog.js`의 `estimate()`, 아일랜드 b + 포틀랜드 기준
  - 아일랜드 690,000 + 설치 120,000 + 바닥재 62,000원/㎡ × 9.5㎡(589,000) + 기존 바닥 철거 350,000
  - 원본 텍스트는 숨김 처리했고, 그 위에 같은 크기로 새 텍스트를 얹었다. 녹화 클립의 XR 화면도 같은 금액이다.
  - 함께 바꾼 표시: 타일 "9.5㎡, 포틀랜드 모티프", 아일랜드 "아떼 원목 식탁, 마호가니"

### E1 문구 (두 버전)

| 버전 | 헤드라인 | 카드 |
|---|---|---|
| 안전형(현재 적용) | 전시에서 Weave를 먼저 체험한 16명이 답했어요 | 16/16명 이용 의향 · 4.5/5 상담 흐름 자연스러움 · 9/16명 '내 공간에 바로 적용해 보기'가 가장 도움 |
| 후킹형 | 직접 써 본 16명 모두 "이용하고 싶다"고 답했어요 | 같은 카드. 첫 카드만 크게 |

구성 의도:
- 수치는 모두 전시 현장 설문(응답 16명)에서 가져왔다. 표본 크기를 화면에 함께 적어, 근거 없이 일반화한 주장처럼 보이지 않게 했다.
- 세 번째 카드는 2-3 장면(내 공간에 바로 적용)과 이어진다. 영상에서 가장 길게 보여 준 장면이 실제로도 가장 도움이 됐다는 근거를 엔딩에서 다시 짚는다.

## 다시 만들기

프로토타입 녹화(전시 PC 권장. 창을 띄우면 GPU를 써서 파노라마가 부드럽다):

```bash
cd mvp && npm i -D playwright && npx playwright install chromium
```

```bash
npm run promo:record -- --headed
```

프리뷰 다시 조립(ffmpeg 필요):

```bash
python3 promo/build-preview.py
```

한 장면만:

```bash
python3 promo/build-preview.py --only 2-3
```

Figma 프레임을 고쳤다면 해당 프레임을 PNG(1x)로 내보내 `promo/frames/`의 같은 이름 파일을 덮어쓴다.
