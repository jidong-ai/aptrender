## 빠른의뢰 화면 구조
- 진입: 대시보드 "전문가" 카드의 [빠른 의뢰 요청] 버튼
- 경로 표시: 프로젝트 대시보드 / 공사 일정
- 좌측 패널(200×788): 공정 범위(면적·평면 썸네일) + 공정 스테퍼(철거·설비·목공·전기·바닥·도배, 각 공정에 배정 업체명)
- 우측: 선택 공정의 전문가 목록(필터: 특화 경력·비용·시공기간), 업체 카드, AI 적합도 카드(예: 87%) + [의뢰 요청]
