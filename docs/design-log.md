### 확정 디자인 기준 (2026-10, 페이지 "디씽 ui/mvp", 최종_대시보드UI 1289-1077)
- 하위 페이지 템플릿 = Web/dashboard/빠른의뢰(1289-799): NAV/closed(인스턴스) + 상단 헤더 그룹(1289-801) + 브레드크럼(1289-831), 콘텐츠 x152~1285
- 패널: 흰색 65% + 흰 테두리 65%, 라운드 36, GLASS + 내부 그림자 2개 + 그림자 #c4e0f2 80% (예: 공사 일정 1289-1456)
- 항목 카드: Grey/10, 라운드 18, 안쪽 여백 8/20. 알약 버튼: 흰색 55% + #205ba5 70% 테두리, Blue/100 Bold 12 + 화살표
- 글자: 패널 제목 Inter Bold 20, 본문 Pretendard Regular 12 / Medium 14 / Bold 14, 공정명 Noto Sans KR 14
- Figma MCP에서 Pretendard를 불러올 수 없어서 새 텍스트는 Noto Sans KR(같은 굵기·크기)로 넣음. 사용자가 피그마에서 Pretendard로 일괄 교체해야 함

스테퍼 컴포넌트: `공정 프로세스 -1`(865-2440, 공정 추가 접힘) / `공정 프로세스 -2`(865-2521, 추가 후보 펼침). 사용자가 Google Calendar UI를 참고해 직접 만듦.
주의: Pretendard는 사용자 로컬 폰트라 Figma MCP에서 편집 불가. 이 폰트를 쓴 텍스트는 사용자가 직접 수정해야 함.
