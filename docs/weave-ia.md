## 공통 도메인 정보 (화면에서 확인한 값)

**프로젝트 단계 (상단 프로그레스바, 6단계)**
취향 무드보드 완성 → 3D 도면 계획 → 일정 수립 → 의뢰 및 공사 계약 → 시공 → 검토

**공정 순서 (공사 일정 간트 / 빠른의뢰 스테퍼)**
철거 → 설비 → 목공 → 전기 → 바닥 → 도배 (→ 검토)

**좌측 내비게이션 아이콘 (위→아래)**
폴더(프로젝트) / 홈 / 장바구니+(자재쇼핑) / 대시보드(편집 아이콘) / 설정 / (하단) 프로필

**샘플 데이터**
- 프로젝트명: 2026 우리집, 진행률 74%, 상태 "시공 중"
- 사용자명: 지윤님
- 공정 범위 예: 약 13m², 화장실·거실 일부
- 예상 견적: 1,830만 원
